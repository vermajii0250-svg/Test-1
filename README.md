# NutriScan - Food Nutrition Scanner 🥗

A lightweight, standalone web application that calculates macronutrients (Carbohydrates, Protein, Fats in grams), calories, and micronutrients from food plate images.

## Features
- **Multi-Dish Identification**: Breaks down meals into individual components (e.g., Grains, Curries, Breads, Salads) with individual portion weights.
- **Macronutrients in Grams**: Detailed Carbohydrates (g), Protein (g), Fats (g), and Total Calories (kcal).
- **Vitamins & Minerals**: Dietary Fiber, Vitamin C, Vitamin A, Vitamin B12, Iron, and Calcium tracking.
- **Today's Macro Target Tracker**: Live progress bar against daily 2,000 kcal & 130g protein targets.
- **Meal Diary & History**: Save scanned meals locally with timestamps and macro summaries.
- **Zero Dependencies**: Single self-contained HTML file running directly in any modern browser.

## How to Host on GitHub Pages (Free Live Website)
1. Create a new repository on [GitHub](https://github.com/new) named `nutriscan`.
2. Upload `index.html` and `README.md`.
3. Go to **Settings** > **Pages**.
4. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
5. Your live app URL will be ready at: `https://<your-username>.github.io/nutriscan/`
